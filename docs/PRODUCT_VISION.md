# PRODUCT_VISION 产品愿景

- 版本：v1.0
- 日期：2026-08-05
- 维护者：CIO（JINZA）｜审核：CTO

## 产品定位

**Linier CRM Management System**

面向中国工业企业、贸易公司、制造业、自动化设备行业的 **CRM + ERP 一体化平台**。

## 目标

替代 **Excel + 微信 + QQ + ERP** 的碎片化管理，为中小型工业企业提供从客户线索、项目跟进、报价、销售、采购、库存到财务的一体化数字化底座。

## 核心能力

```
CRM
Project（项目型销售全生命周期）
Quotation
Sales
Purchase
Inventory
Finance
BI
```

## 原则

- **Mobile First**：移动端优先（Sprint 10）
- **API First**：一切能力走 API，前端可替换
- **Multi Tenant Ready**：多租户就绪
- **RBAC**：角色权限 + 动作级细粒度权限
- **Audit**：全量审计日志
- **Workflow**：审批流驱动业务

## 目标行业

- 机床 / 自动化设备制造
- 直线导轨、轴承、传动件等零部件制造与贸易
- 通用工业品贸易与代理
- 需要"项目型销售 + 进销存"一体化的中小型制造企业

## 用户角色

| 角色 | 需求 |
| --- | --- |
| 老板 / 总经理 | 看板：销售漏斗、项目进展、回款、库存、利润 |
| 销售 / 项目经理 | 客户、机会、项目、报价、订单、回款跟进 |
| 采购 | 请购、采购订单、收货、供应商管理 |
| 仓库 | 库存、出入库、盘点、调拨 |
| 财务 | 应收应付、费用、凭证、利润、现金流 |
| 管理员 | 用户、角色、权限、字典、参数、菜单 |

## 商业模式

- 私有化部署 + 订阅制（SaaS 可选）
- 按模块授权（CRM / 进销存 / 财务 / BI）
- 实施与培训服务（AI 员工 / SOP 落地）

## 核心竞争力

1. **项目型销售全生命周期**：机会 → 项目 → 报价 → 订单 → 交付 → 回款，适合工业项目制业务
2. **中国工业企业字段标准**：统一社会信用代码、含税价格体系、13% 税率可配置、17 种单据编号
3. **ERP 底座先行**：Workflow / Approval / Notification / Dictionary / File Center 先于业务模块，业务开发效率高
4. **数据驱动决策**：Dashboard API + BI 让老板实时掌握经营数据

## 系统边界

- 本系统覆盖：客户、项目、报价、销售、采购、库存、财务、BI
- 不替代：专业财务软件（金蝶/用友）的法定报表，本系统输出数据可导出对接
- 不替代：生产执行（MES/ERP 生产模块），Sprint 6 只做库存，生产加工在 Scope 外（见 ROADMAP）

## 不做什么（Out of Scope）

- ❌ 营销自动化（邮件群发、广告投放）
- ❌ 客服工单系统
- ❌ 社交/协同 IM（企业微信/钉钉仅做消息对接）
- ❌ 生产计划与车间执行（MES）
- ❌ 原生移动 App（Sprint 10 之前仅响应式 Web）
- ❌ 多币种复杂结算（默认 CNY，扩展留接口）
