# ADR-0011：BusinessPartner Consolidation（统一迁移规划）

- 状态：Accepted（规划项，Sprint 5 执行）
- 日期：2026-08-06
- 关联：ADR-0009（Customer Foundation）、ADR-0010（Supplier Foundation）、ARCHITECTURE_BASELINE v1.0

## 背景

CTO 审阅 3C-2 设计后确定长期方向：**BusinessPartner 为唯一主体，Customer / Supplier 均为其角色（Role），而非继承**。
3C-1 已交付的 Customer 子模型（CustomerContact / CustomerAddress / CustomerTag / CustomerCredit）与 3C-2 新建的
Partner 级共享模型（PartnerContact / PartnerAddress / PartnerTag / PartnerBankAccount / PartnerCredit）在语义上重复。

CTO 决定：**Customer 不返工**。当前已交付的 Customer 模型保留兼容，统一迁移列入 Sprint 5 架构优化，
避免打断 Sprint 3C 开发节奏。

## 决策

### 1. Sprint 3C-2 不迁移 Customer
- 3C-1 的 CustomerContact / CustomerAddress / CustomerTag / CustomerCredit 保持现状，API 不变。
- 3C-2 仅新增 Partner 级共享模型，Supplier 直接使用共享表。

### 2. Sprint 5 统一迁移目标模型
```
BusinessPartner（唯一主体，type 兼容字段保留）
  ├── BusinessPartnerRole（CUSTOMER/SUPPLIER/BOTH/LOGISTICS/OUTSOURCING）
  ├── PartnerContact        ← 合并 CustomerContact
  ├── PartnerAddress        ← 合并 CustomerAddress（PartnerAddressType 含 Billing/Shipping/Registered/Warehouse/Factory/Invoicing/Contact）
  ├── PartnerTag            ← 合并 CustomerTag
  ├── PartnerBankAccount    ← 新增统一（收付款共用）
  ├── PartnerCredit         ← 合并 CustomerCredit（AR/AP 统一）
  ├── Customer（角色扩展，保留业务字段）
  └── Supplier（角色扩展）
```

### 3. 迁移策略（Sprint 5）
- 数据迁移：CustomerContact → PartnerContact（customer.partnerId 关联），CustomerAddress → PartnerAddress，
  CustomerTag → PartnerTag，CustomerCredit → PartnerCredit。
- 代码迁移：Customer 子资源 API 改为读写 Partner 共享表（视图兼容），删除 Customer* 子表（经 ADR 批准后）。
- 枚举统一：CustomerCreditRating/CustomerCreditStatus 在 PartnerCredit 中复用，Sprint 5 评估是否统一命名。
- 兼容期：迁移期间 Customer API 与 Partner API 双写（feature flag），验证一致后切换。

### 4. 验收条件（Sprint 5）
- Customer 与 Supplier 的联系人/地址/标签/信用/银行全部走 Partner 级共享表。
- Customer 旧 API 兼容（返回结构不变）或按 API_GUIDELINES 版本化迁移。
- 无重复数据、无孤儿记录。

## 影响

- Sprint 3C-2 不受影响（Supplier 直接使用共享模型）。
- Sprint 5 需要新 ADR 细化执行方案（本 ADR 为方向性决策）。
- 前端若已使用 CustomerContact 等字段，Sprint 5 需同步调整。

## 权衡

- 立即迁移 vs 延后到 Sprint 5：立即迁移会重写 Customer 全部代码（PR #7 刚合并即返工）；
  延后迁移保留兼容、节奏稳定，代价是短期存在两套子模型（通过 ADR-0010 的共享表作为长期目标收敛）。
