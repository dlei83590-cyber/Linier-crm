# ADR-0047：材料成本差异（发票净额 vs 暂估价）

- 状态：**Accepted（Implemented，2026-08-20）**
- 日期：2026-08-20

- 关联：CTO_Repo_Audit_2026-08-20（中国环境审计 **P1：发票价差无科目承接，存货成本与 AP 口径漂移**）、ADR-0033/0038-0041

---

## 背景

入库成本按 PO 快照价（GRIR baseAmount）暂估入账（ADR-0038）；发票 POSTED 时按发票净额（net+nonRecoverable）入 1403——二者差异（价格差异）无科目承接，存货成本与 AP 入账口径漂移。

## 决策

1. **科目**：seed +`1404 材料成本差异`（ASSET/DEBIT）。
2. **GL 映射修正（SupplierInvoicePosted）**：存货成本按**暂估入账**——`借 1403 = Σ GRIR CONSUME baseAmount（该发票已消耗暂估）`；差额 `variance = 发票净额(含不可抵扣税) − Σ暂估` 入 `1404 材料成本差异`（借/贷按符号）；借贷平衡（1403 + 1404 + 222101 = 2202）。
3. **防御**：无已消耗暂估（accrualBase=0）时回退原路径（1403=发票净额，无 1404 行）——不破坏既有数据/测试。
4. **单测**：暂估 90 vs 发票净额 100 → 借 1403=90 + 借 1404=10（借贷平衡）。

## 边界

- 差异的月末结转/分摊（差异率分配至发出存货）为 backlog；仅在建账层承接差异。
