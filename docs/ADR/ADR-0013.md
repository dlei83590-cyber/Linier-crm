# ADR-0013：Price Foundation Architecture（价格领域架构）

- 状态：Approved（CTO #2249 批准进入实现阶段；Sprint 3C-4）
- 日期：2026-08-06
- 关联：ADR-0012（Item Master）、PRICE_STRATEGY.md、MASTER_DATA_DEPENDENCY.md、ARCHITECTURE_BASELINE v1.0
- 编号说明：CTO #2225 批准使用 **ADR-0013**（ADR-0012 已用于 Item Foundation，ADR 编号必须唯一，禁止复用）

## 背景

Sprint 3C-4 启动 Price Foundation（原 3C-5，CTO #2138 提前至 3C-4，因 Price 依赖 Customer/Supplier/Item 均已就绪）。
Price 是销售（Quotation/SO）与采购（PO）的价格引擎，必须与主数据解耦、支持版本化与策略化。

## 决策

### 1. Price 独立于 Item（Item 无价格字段）
- Item 是主数据，价格是业务数据，生命周期不同；价格通过 PriceListItem / PartnerPrice 关联 Item。
- **不在 Item 上增加任何价格字段**（CTO #2204/#2225）。

### 2. 采用 Version（PriceListVersion）
- PriceList 有 PriceListVersion（Draft → Published → Archived，versionNo 递增）。
- 报价可追溯：改价不覆盖历史，发布新版本；历史价格通过版本解释。

### 3. 采用 Policy（PricePolicy 独立建模）
- PricePolicyType：STANDARD / VIP / PROJECT / DEALER / REGIONAL / PROMOTION。
- **双轨模式（CTO #2225 批准）**：PriceList 同时持有 `pricePolicyId`（FK 关联当前策略）+ `policyType`（快照）。
  - pricePolicyId：关联当前策略，策略可调整。
  - policyType：保留快照，即使策略以后修改，历史价格仍能准确解释。
- 策略类型不写死在 PriceList 业务代码中，独立建模 + priority 排序。

### 4. CustomerPrice / SupplierPrice 不直接写入 Item
- 价格不落在 Item 表，通过关联表表达；同一 Item 可同时有价目表价、客户专属价、供应商价。

### 5. 价格挂 Partner 级（CTO #2225 长期方向）
- 数据库底层统一 **PartnerPrice**（partnerId → BusinessPartner，roleType 区分 CUSTOMER/SUPPLIER/BOTH）。
- API 继续暴露 `/customer-prices`、`/supplier-prices` 视图（读 PartnerPrice，写时校验 roleType）。
- Customer 模型（3C-1）继续兼容不返工，Sprint 5 统一迁移（ADR-0011 框架下）。

### 6. Promotion 独立（PromotionRule）
- PromotionRule 独立建模（PERCENT/AMOUNT + 有效期 + 状态），不写进 PriceList。
- 以后 Quotation / Campaign / Customer Group 都会引用（CTO #2225 批准独立）。

### 7. TaxProfile 独立 + 环境默认（CTO #2225）
- TaxProfile（0% / 6% / 13% / 免税 / 自定义），适配多国税率。
- **不直接依赖 DEFAULT_TAX_RATE 存税率**；改为 `ENV DEFAULT_TAX_PROFILE_CODE` → 默认 TaxProfile（环境变量只负责默认 Profile，不直接存税率）。
- 中国/马来西亚/新加坡切换 = 切换环境默认 Profile，税率数据不变。

### 8. Currency 多币种（Base/Quote + ExchangeRateReference）
- PriceList 支持 baseCurrency / quoteCurrency；ExchangeRateReference 记录汇率（base/quote/rate/rateSource/effectiveDate）。
- 不写死汇率，汇率来源可配置（央行/银行/自定义）。

### 9. 统一时间窗口（effectiveFrom / effectiveTo）
- 所有价格记录支持 effectiveFrom / effectiveTo（非仅 validFrom）；查询时 `NOW() BETWEEN effectiveFrom AND effectiveTo`。

### 10. 新增能力（CTO #2225）
- **PriceSource**：MANUAL / IMPORT / FORMULA / PROMOTION / SUPPLIER / MARKET（BI 分析价格来源）。
- **PriceApproval**：价格修改（创建/更新明细、发布版本）通过 Workflow/Approval 审批后生效（approvalStatus 复用全局枚举）。
- **PriceSnapshot**：Quotation 报价时固化 QuotationPriceSnapshot（不实时读 PriceList），保证报价历史价格可追溯。
- **PriceEngine 接口**：定义接口（getSellingPrice / getPurchasePrice / getPromotion / getTax / getCurrency），今日不实现；Quotation（Sprint 4）直接调用。

## 影响

- Schema（设计草案）：+9 模型（PricePolicy / TaxProfile / ExchangeRateReference / PriceList / PriceListVersion / PriceListItem / PartnerPrice / PromotionRule）+ 3 枚举（PricePolicyType / PriceListStatus / TaxRateType / PriceSource）→ 预计 96+ 模型 / 43+ 枚举。
- 复用：Item（3C-3）/ BusinessPartner（Sprint 2）/ Workflow（3A）/ File（3B）。
- RBAC（实现期）：price-list / price-list-item / price-list-version / customer-price / supplier-price / price-policy / tax-profile / promotion（8 模块；price-list 已存在补全动作级，其余 7 新增）。
- API（实现期）：约 24 端点（price-lists 主档+发布+明细+版本 / customer-prices / supplier-prices / price-policies / tax-profiles / promotions）。
- 迁移（实现期）：`0012_price_foundation`（仅新增，不改既有表）。

## 权衡

- PartnerPrice 统一 vs CustomerPrice/SupplierPrice 分表：统一表减少模型膨胀、支持 BOTH 角色；API 视图隔离语义。Customer 侧迁移延后（Sprint 5）。
- 双轨 policyType 快照 vs 仅 FK：快照保证历史可解释，代价是冗余一个枚举字段；可接受。
- PriceEngine 接口先行 vs 直接实现：接口先行保证 Quotation 依赖稳定，实现归 3C-4 实现阶段。

## 待确认（CTO 决策项，实现前）

1. PartnerPrice.roleType 用枚举（PartnerRoleType）还是字符串快照？
2. PriceSnapshot 是否也覆盖 PromotionRule 命中结果（快照含促销价）？
3. 定价引擎优先级配置：PricePolicy.priority 是否足以表达全部策略组合（PROMOTION > CUSTOMER > VOLUME > REGIONAL > STANDARD）？


## 补充决定（CTO #2249，2026-08-06）

### 11. PartnerPrice.roleType：枚举 + 快照
- `partnerRoleType`（枚举 PartnerRoleType：CUSTOMER / SUPPLIER / BOTH / LOGISTICS / OUTSOURCING）——业务逻辑/查询/权限判断用。
- `partnerRoleName`（字符串快照，可选）——避免以后角色名称调整影响历史显示。
- **不用纯字符串**：字符串无法保证查询一致性、易产生拼写与历史兼容问题。

### 12. QuotationPriceSnapshot：必须含促销命中结果（保存整个定价过程）
- 快照保存完整定价链：Base Price → Price Policy → Discount → Promotion（命中规则）→ Tax Profile → Exchange Rate → Final Price。
- 至少记录：PriceList、PricePolicy、PromotionRule、PromotionDiscount、Currency、ExchangeRate、TaxProfile、TaxRate（快照）、FinalUnitPrice、FinalAmount、PricingTime、**PricingEngineVersion**（新增）。
- 以后价格/税率/促销规则变化，历史报价仍可完全复原。

### 13. PricePolicy：priority 不够，新增 matchStrategy + stopOnMatch
- `matchStrategy`：FIRST_MATCH / BEST_PRICE / LOWEST_PRICE / HIGHEST_PRIORITY / COMBINE。
- `stopOnMatch`：true/false（第一条命中即停 / 继续匹配叠加 / 按优先级继续）。
- 支持复杂策略：仅 priority 无法表达。

### 14. PriceEngine：统一入口 resolvePrice()
- 批准接口；新增统一入口 `resolvePrice()`，内部编排调用 getSellingPrice / getPurchasePrice / getPromotion / getTax / getCurrency。
- Sprint 4 Quotation、Sprint 5 Purchase 只调用一个入口。

### 15. 新增 ExchangeRate 表（独立维护，不依赖外部实时查询）
- Base Currency / Quote Currency / Rate / Effective Date / Source（CUSTOM/BANK/CENTRAL_BANK/MARKET）。
- 唯一约束 [baseCurrency, quoteCurrency, effectiveDate]；历史追溯 + 财务结账。

### 16. 新增 TaxProfileRule 表（多国税制规则，不改核心代码）
- Country / Item Category / Customer Type / Supplier Type / Tax Code / Priority。
- 中国/马来西亚/新加坡切换：配置规则即可，支持未来扩展。

### 17. Sprint 3C 后续顺序（正式调整）
- Price Foundation（当前）→ Project Foundation → Sprint 4 Quotation / Sales。
- Quotation 直接建立在完整 Price Engine 之上。
