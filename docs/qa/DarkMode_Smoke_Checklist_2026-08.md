## 冒烟步骤

1. **主题切换**：登录 → 顶栏右侧（命令面板按钮旁）点击月亮/太阳图标
   - [ ] 切换到暗色：整页背景/文字/卡片/边框变为暖暗色（非纯黑，暖炭黑系）
   - [ ] 再次切换回亮色：恢复暖白
   - [ ] 刷新页面：主题保持（localStorage linier.theme 记忆）
   - [ ] 图标随主题切换（暗色显示太阳、亮色显示月亮）+ aria-label 正确

2. **壳层**：
   - [ ] 侧栏（折叠/展开/域色指示条/手风琴）、顶栏（搜索/快捷创建/命令面板/用户菜单）、移动端抽屉
   - [ ] 域色图标底（50 档）在暗色下为深色调、域色文字可读

3. **列表页**（抽查 sales/orders、supplier-invoices、business-partners）：
   - [ ] KPI 状态卡、筛选 chips、表格行 hover、行内 ⋯ 菜单、分页、列设置
   - [ ] 金额右对齐 tabular-nums 可读、状态徽章三元组深色可读

4. **详情页**（抽查 sales/orders/[id]、supplier-invoices/[id]、gl-journal-entries/[id]）：
   - [ ] 摘要区、状态动作栏、复制按钮、行明细表、审计时间线、Donut 底环

5. **表单页**（抽查 quotations/new、transfers/new、gl-journal-entries/new）：
   - [ ] 输入框/下拉/Combobox、行编辑表、字段错误文案、禁用态

6. **仪表盘 + 报表**：
   - [ ] KPI 卡、洞察区 Bento 布局、Donut（商机/订单分布）、MiniBar、利润表/试算平衡表格

7. **弹层/反馈**：
   - [ ] 对话框（遮罩 bg-scrim 深色更高不透明）、Toast、命令面板、骨架屏（深色骨架）

8. **打印**（报价单 print 页）：
   - [ ] 暗色模式下打印：白底黑字（Phase 3 修复：打印强制亮色变量覆盖）

## 已知可接受项（非缺陷）

- 仪表盘/报表的数据可视化条色（STAGE_COLORS / SO_STATUS_BAR_HEX / DRAFT 条 bg-slate-400）为业务投影色，不跟随主题——深色下仍可读
- 登录页品牌区渐变装饰（bg-white/10-15）与品牌按钮 text-white 双主题保持
