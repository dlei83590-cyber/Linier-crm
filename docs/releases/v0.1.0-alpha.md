## 部署步骤（远程测试/生产服务器）

```bash
git checkout feature/sprint1-infrastructure   # 或 merge 后的 main

# 1. 环境变量
cp .env.example .env
# 编辑 .env：DATABASE_URL / NEXTAUTH_SECRET / NEXTAUTH_URL / POSTGRES_PASSWORD

# 2. 依赖（lockfile 存在后用 frozen）
pnpm install --frozen-lockfile

# 3. Prisma
pnpm prisma generate
pnpm prisma migrate deploy
pnpm prisma db seed

# 4. 构建
pnpm build

# 5. 启动（生产 compose）
docker compose -f docker-compose.prod.yml up -d --build

# 6. 健康检查
curl -i http://localhost:3000/api/health
# 期望: HTTP/1.1 200 OK + {"status":"ok","service":"linier-crm","version":"0.1.0-alpha",...}
```

## 回滚步骤

```bash
# 停止并移除容器（保留数据卷）
docker compose -f docker-compose.prod.yml down

# 回滚代码到上一个稳定提交
git checkout <previous-stable-sha>

# 如需回滚数据库（谨慎：仅当迁移引入破坏性变更）
# 1) 找到上一个 migration 名
# 2) 手动执行对应的降级 SQL（Prisma 不自动生成 down migration，需人工编写）
# 3) pnpm prisma migrate deploy 重新对齐
```
